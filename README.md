# Pulso Austral 🚀

Plataforma web para conectar emprendedores en Río Grande, Tierra del Fuego.

## 📋 Descripción
Proyecto desarrollado con Flask y SQL para centralizar la oferta de emprendimientos locales, permitiendo filtrar por rubro (Gastronomía, Tecnología, etc.) y zona.

## 🛠️ Tecnologías
* **Backend:** Python, Flask, SQLAlchemy
* **Base de Datos:** SQLite
* **Control de Versiones:** Git & GitHub

## ⚙️ Instalación
1. Clonar el repositorio.
2. Crear entorno virtual: `python -m venv venv`
3. Instalar dependencias: `pip install Flask Flask-SQLAlchemy`
4. Ejecutar: `python app.py`
